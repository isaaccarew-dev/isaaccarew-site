# Isaac Carew Site

A clean and modern static site ready for GitHub Pages.

## Files

1. index.html
2. shop.html
3. css/style.css
4. js/main.js
5. CNAME

## Publish on GitHub Pages

1. Create a new repository on GitHub.
2. Add all files in this folder to the root of the repository.
3. In repository settings open the Pages section.
4. Choose the main branch and root folder, then save.
5. Set the custom domain to isaaccarew.com and allow the DNS check to complete.

## Local Preview

Open index.html in your browser. You can also use any simple local server if you prefer.
